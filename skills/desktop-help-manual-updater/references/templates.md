# 参考模板

## 路线判断记录

```md
| 维度 | 观察 | 结论/影响 |
| --- | --- | --- |
| 现有手册覆盖率 | 例如：约 80% 核心模块已存在 | 倾向增量更新 |
| 现有结构可复用性 | 例如：目录结构基本合理，但若干步骤过时 | 倾向大幅重写 |
| 现有术语可复用性 | 例如：术语稳定，可保留 | 保留既有术语 |
| 可用资料完整度 | 例如：只有发行说明，没有成型手册 | 倾向从零编写 |
| 最终路线 | 增量更新 / 大幅重写 / 从零编写 | 填写最终结论 |
| 是否需要询问人类 | 是 / 否 | 说明原因 |
```

## 差异更新计划

```md
| 章节/模块 | 当前判断 | 处理动作 | 依据 | 负责人/方式 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 快速开始 | 大概率可复用 | 抽样复核 | 首页结构未见明显变化 | 实机核验 | 仅需换截图时再重写 |
| 历史记录 | 必须重新核验 | 全量检查 | 导航和筛选能力疑似改版 | 实机核验 | 关注空态/筛选/批量操作 |
| 导出结果 | 明显过时 | 重写 | 旧手册格式描述与当前 UI 不符 | 实机核验 + 文件落盘 | 需要闭环验证 |
```

状态建议使用：

- `大概率可复用`
- `必须重新核验`
- `明显过时`
- `缺失待补`

处理动作建议使用：

- `保留`
- `抽样复核`
- `全量检查`
- `重写`
- `补充新增章节`

## 从零编写手册大纲

```md
# <产品名称> 帮助手册

## 1. 产品简介

## 2. 使用前准备

## 3. 界面总览

## 4. 快速开始

## 5. 核心功能
### 5.1 <模块一>
### 5.2 <模块二>

## 6. 常见操作

## 7. 数据导入、导出或管理

## 8. 常见问题 / 注意事项
```

说明：

- 只保留真实存在且经过核验的章节
- 如果项目需要多文件拆分，仍建议保留 `index.md` 作为总入口
- 如果目标产品没有“数据导入、导出或管理”类能力，可删除该章节

## 演示数据检查清单

```md
- 是否符合当前应用的真实使用语境
- 是否覆盖核心功能需要的文件类型或文本类型
- 是否避免出现明显测试垃圾词
- 是否避免使用真实敏感信息
- 是否与截图和手册中的场景描述一致
```
